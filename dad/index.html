1초대 수락하기

리치가 아버지 스레드 계정(@sangun.dbclass)으로 초대를 보냈어요. 폰 인터넷(사파리·크롬)에서 수락하시면 돼요. 스레드 앱에는 이 메뉴가 안 보일 수 있어요.

  1. 이 주소를 누르세요: threads.com/settings/account
  2. 스레드에 로그인하세요 (평소 쓰시는 @sangun.dbclass).
  3. 웹사이트 권한을 누르세요.
  4. 초대에서 아버지의 스레드 옆 수락을 누르세요.
메뉴가 영어로 보이면: Website permissions → Invites → Accept
수락하면 "초대 수락됨"이라고 떠요. 그걸로 1번은 끝이에요.

2앱에서 연결 누르기

  2. 처음 한 번 "ngrok" 안내 화면이 나오면 Visit Site를 누르세요.
  3. 구글 로그인 화면이 나오면 fcamember@gmail.com으로 로그인하세요.
  4. 앱 위쪽 스레드 연결하기를 누르세요.
  5. 스레드 화면에서 sangun.dbclass(으)로 계속을 누르세요.
이 연결은 아버지 계정에만 쓰여요. 앱은 아버지가 올리기를 누르실 때만 글을 올려요. 마음대로 올리지 않아요.
